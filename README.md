# Kabelfernsehen

Lineares Fernsehen zum Zappen: ein schlanker Player für die frei empfangbaren Livestreams der öffentlich-rechtlichen Sender.

- `index.html` – der Player (läuft im Browser und in der Fire-TV-App)
- `app/` – Android-Hülle für Fire TV
- Bei jeder Änderung baut GitHub die App neu und legt sie unter `https://florianeqcollective.github.io/kabelfernsehen/tv.apk` ab.

Senderliste ändern: oben in `index.html` im Block `SENDER`.
